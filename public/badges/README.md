# Official store badges

Downloaded unchanged on 2026-09-16 for links to Dee’s store listings.

- `app-store.svg`: https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg
  Guidelines: https://developer.apple.com/app-store/marketing/guidelines/
- `google-play.svg`: `GetItOnGooglePlay_Badge_Web_color_English.svg` from Google’s Partner Marketing Hub, Digital → svg → English.
  Source and guidelines: https://partnermarketinghub.withgoogle.com/brands/google-play/google-play/lockups-icons-badges/?folder=86718

Preserve artwork, proportions and clear space. Both badges render at 48px tall, with the App Store first. Platform trademark credits appear in the landing-page footer.
